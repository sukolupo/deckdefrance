Information

Once streaming is started, the app will continuously read power data from your Tacx trainer and send it to the virtual controller for Tour de France to process.

  • Make sure your trainer is configured and selected in the Configuration tab
  • The trainer should be connected and ready before starting the stream
  • The virtual gamepad will emit power values on the Right Trigger (ABS_RZ)
  • Click "Stop Streaming" to safely disconnect and stop data transmission
  • Use Controller Passthrough to forward Steam Deck inputs through the Tacx pad so the game sees one combined controller

Controller Passthrough

Forward Steam Deck controller inputs through the Tacx Virtual Gamepad. This lets the game see one controller that combines Steam Deck controls + trainer power. Configure the game in Steam to use the "Tacx Virtual Gamepad" as player 1.

How It Works

1. Pair your Bluetooth controller with the Steam Deck (Settings → Bluetooth).
2. Click Scan to find it in the list below.
3. Select it and click Start Merge.
4. The controller's inputs and the Tacx trainer's mapped outputs now feed into one virtual gamepad.
